# Swarm_collaboration_via_stigmergy
To explore if stigmergy based communication can improve application of decentralized swarm systems compared to centralized systems.

## Run 
To run stigmergy and centralized approach for a specific scenaio with visualizations:
```
python stigmergy_with_visualization.py
python centralized_approach_with_visualization.py
```

To run experimentation without visualizations:
```
python stigmergy_experimentation_with_evaporation.py
python stigmergy_experimentation_without_evaporation.py
python centralized_experimentation.py
```

## Results
All results will be saved in the form of excel sheets in experiments folder.
